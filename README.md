# ☕ Kopi Sandikala

Kopi Sandikala adalah website company profile untuk sebuah coffee shop yang mengangkat konsep kopi Indonesia dengan tampilan modern, elegan, dan minimalis.

Website ini dirancang untuk memberikan informasi mengenai Kopi Sondokala, mulai dari cerita brand, pilihan menu, kategori produk, testimoni pelanggan, hingga informasi kontak.

---

## 📌 Tentang Website

Website Kopi Sondokala menggunakan konsep dark elegant dengan kombinasi warna hitam dan kuning/gold sebagai warna utama.

Tampilan website dibuat sederhana tetapi tetap menarik dengan fokus pada visual produk kopi dan informasi yang mudah dipahami oleh pengunjung.

### Konsep Website

* Modern
* Minimalis
* Elegan
* Dark theme
* Nuansa coffee shop
* Menggunakan aksen warna kuning/gold
* Responsive untuk berbagai ukuran layar

---

## 🎯 Tujuan

Website ini dibuat sebagai media informasi dan company profile untuk memperkenalkan Kopi Sondokala kepada calon pelanggan.

Melalui website ini, pengunjung dapat:

* Mengenal Kopi Sondokala
* Melihat cerita dan konsep coffee shop
* Melihat menu kopi
* Melihat kategori menu
* Membaca testimoni pelanggan
* Melihat informasi kontak
* Melakukan pemesanan melalui tombol yang tersedia

## 🎨 Design

Website menggunakan konsep **Dark Coffee Elegant**.

### Warna Utama

| Warna     | Keterangan                 |
| --------- | -------------------------- |
| `#000000` | Background utama           |
| `#FFFFFF` | Warna teks utama           |
| `#D4AF00` | Aksen gold/kuning          |
| `#333333` | Border dan elemen tambahan |

Warna gold digunakan sebagai aksen untuk:

* Button
* Heading tertentu
* Icon
* Highlight text
* Garis dekorasi
* Link dan informasi penting

## 🌿 Git Branch

Jika project menggunakan branch, contoh alurnya:

```text
main
 │
 └── develop
       │
       └── feature/website
```

Untuk membuat branch baru:

```bash
git checkout -b feature/website
```

Setelah selesai mengerjakan fitur:

```bash

git push -u origin feature/website
```

Kemudian branch dapat digabungkan melalui Pull Request di GitHub.
